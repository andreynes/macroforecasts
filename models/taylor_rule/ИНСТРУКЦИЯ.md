# «Модели ЦБ» (правило Тейлора): как обновлять самому

Модель считает, какую ключевую ставку «подсказывает» правило ЦБ при прогнозах ЦБ и при нашем прогнозе.
Результат — вкладка «Модели ЦБ» на сайте. Методика подробно — `README.md` в этой папке.

Папка: `/Users/andrejkrylov/Desktop/projectmacro/macro_forecast_site/models/taylor_rule`

---

## Шаг 0. Открыть терминал в этой папке

**Терминал macOS:** `Cmd + Пробел` → «Терминал» → Enter, затем:
```bash
cd /Users/andrejkrylov/Desktop/projectmacro/macro_forecast_site/models/taylor_rule
PY=/Users/andrejkrylov/anaconda3/bin/python3
```
**VS Code:** откройте папку сайта (File → Open Folder… → `projectmacro/macro_forecast_site`), Terminal → New Terminal,
и выполните две строки выше.

Проверка: `ls src` показывает `download_data.py`, `export_site.py`, `taylor_rule.py`.

---

## Когда обновлять

1. **После каждого изменения нашего прогноза** (вкладка «Макропрогнозы», файл `macro_main_linked.xlsx`, после
   `data_scripts/update_macro.py`) — иначе на вкладке останется старый прогноз СКБ.
2. После заседания ЦБ / нового среднесрочного прогноза ЦБ.
3. После выхода новых данных по инфляции или ВВП.

## Шаг 1. Скачать свежие данные

```bash
$PY src/download_data.py
```
1–3 минуты. Скачиваются ключевая ставка и ИПЦ (ЦБ), ВВП (Росстат), PDF среднесрочных прогнозов ЦБ.
Если упало из-за интернета — запустите ещё раз.

**Инфляция и базовая инфляция** берутся из файла `data/ИПЦ и БИПЦ.xlsx` (выгрузка ЕМИСС, периоды в столбцах).
Чтобы обновить: выгрузите с fedstat.ru ИПЦ и базовый ИПЦ в формате **.xlsx** (не .xls — он обрезается) и замените файл.

## Шаг 2. Пересчитать и записать данные для сайта

```bash
$PY src/export_site.py
```
1–2 минуты. Результат — `macro_forecast_site/data/cbr_models.json` (на экране будет путь).

## Шаг 3. Посмотреть и выложить

```bash
cd /Users/andrejkrylov/Desktop/projectmacro/macro_forecast_site
$PY app.py
```
В браузере — http://127.0.0.1:5050/cbr-models (остановить — `Ctrl + C`).
Выложить сайт — по `macro_forecast_site/ИНСТРУКЦИЯ.md`, раздел про выкладку.

## Ручные допущения (файл `src/taylor_rule.py`)

Откройте файл в VS Code, найдите название через `Cmd + F`, поправьте число, сохраните (`Cmd + S`), повторите шаг 2.
- `EXTRA_DEC_FORECASTS` — наш прогноз инфляции на декабри за пределами файла прогнозов (сейчас ИПЦ на дек-2028 — 5,0%);
- `GDP_YOY_PRELIM` — предварительные оценки роста ВВП г/г по кварталам (считаются фактом);
- `GDP_YOY_FORECAST` — наши допущения по росту ВВП на ближайшие кварталы;
- `NEUTRAL_NOMINAL` — диапазоны нейтральной ставки ЦБ по периодам.

## Частые проблемы

| Симптом | Что делать |
|---|---|
| `ModuleNotFoundError` | запущен не тот Python — используйте `$PY` |
| Ошибка скачивания в шаге 1 | повторите позже |
| На вкладке старый прогноз СКБ | не запустили шаг 2 после обновления «Макропрогнозов» |
| Ряд инфляции обрывается на 2020 г. | файл ИПЦ сохранён как `.xls` — нужен `.xlsx` |
