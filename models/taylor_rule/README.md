# Репликация правила Тейлора Банка России

## Правило (КПМ ДДКП, Орлов 2021; Орлов, Шарафутдинов 2024)

    i_t = ρ·i_{t-1} + (1-ρ)·[ r̄_t + πᵉ_{t+3} + φπ·(πᵉ_{t+3} − 4) + φy·ŷ_t ]

Калибровка из опубликованного кода ЦБ (`Материалы/Код КПМ/КПМ_ДДКП/model/parameters_main.mod`):
ρ = 0,75; φπ = 1,5 (1,9 — «жёсткая ДКП»); φy = 0,5; цель 4%; r̄ в стационаре ≈ 4%.
В модели πᵉ — взвешенная базовая (0,75) и общая (0,25) инфляция г/г через 3 квартала.

КПМ ДИП (`Материалы/Код КПМ/КПМ_ДИП/models`): ρ = 0,63; φπ = 1,5; без разрыва выпуска; инфляция через 4 квартала; r̄ = 4%.

    pip install -r requirements.txt
    python src/download_data.py   # ЦБ: ключевая ставка, ИПЦ г/г; Росстат: ВВП с искл. сезонности

## Входные данные вне `data/raw`

* `data/ИПЦ и БИПЦ.xls(x)` — выгрузка ЕМИСС (ИПЦ и базовый ИПЦ, периоды в столбцах).
  Формат `.xls` обрезается на 256 столбцах (≈ до середины 2020 г.) — для полного ряда нужен `.xlsx`.
* `FORECAST_FILE` (`projectmacro/macro_forecast_site/macro_main_linked.xlsx`, лист `main`) — наш прогноз:
  ИПЦ г/г (м), ключевая ставка (м, на конец месяца), ВВП г/г (год). Используется для
  ожиданий инфляции после последнего факта, продления ВВП (разрыв выпуска) и сравнения с правилом.
* `EXTRA_DEC_FORECASTS` в `src/taylor_rule.py` — наш прогноз инфляции на декабри за пределами файла
  (сейчас ИПЦ на декабрь 2028 — 5,0%, БИПЦ — через спред); месяцы между — по прямой. Нужен, т.к. правило смотрит на 3 квартала вперёд.
* `GDP_YOY_PRELIM` / `GDP_YOY_FORECAST` в `src/taylor_rule.py` — рост ВВП г/г по кварталам вне файла Росстата:
  предварительные оценки (считаются фактом; сейчас 2026Q3 +0,7%) и наши ручные допущения на прогнозе
  (сейчас 2026Q4 +0,3%). Дальше — годовой прогноз из FORECAST_FILE (уровень подбирается под среднегодовой рост).

## Реализация (версия 2 — калибровка ЦБ + наш прогноз)

| Элемент | Как сделано | Отличие от КПМ |
|---|---|---|
| Ставка | ключевая, среднее за квартал | в КПМ — ставка МБК (близка к ключевой) |
| Инфляция | основной `pi_mix` = 0,75·БИПЦ + 0,25·ИПЦ; для сравнения `cpi_yoy` (общий ИПЦ) и `pi_mix_eq` (БИПЦ = ИПЦ на прогнозе) | как в КПМ |
| Прогноз БИПЦ | показатель «Базовая инфляция» из FORECAST_FILE, если есть; иначе прогноз ИПЦ − спред (ИПЦ − БИПЦ): текущий (среднее за `SPREAD_NOW_MONTHS` = 3 мес.) до конца 2026 г., в течение `SPREAD_CONVERGE_YEAR` = 2027 г. линейно к среднему за `SPREAD_LONG_MONTHS` = 36 мес., дальше постоянный | — |
| Ожидания | `fwd` — инфляция через h кв.: факт, далее наш прогноз; `cur` — текущая | в КПМ — модельные (смесь адаптивных и рациональных) |
| Разрыв выпуска | HP (λ=1600) по ВВП в ценах 2021 г. с 2011Q1, продлённому нашим годовым прогнозом; двусторонний и односторонний (только факт) | в КПМ — фильтр Калмана по всей модели |
| Нейтральная ставка | официальные диапазоны ЦБ по периодам (`NEUTRAL_NOMINAL` в коде) или 4% реальных из КПМ | в КПМ — r̄ из UIP |

Варианты расчёта правила: `notional` — без сглаживания; `one_step` — с лагом ставки (факт, далее наш прогноз);
`dynamic` — рекурсивно от 2015Q1; `path_fcst` — рекурсивно от последней фактической ставки (траектория по правилу на прогнозном горизонте).

Главный выход для прогноза — лист «Прогноз vs правило» и `outputs/forecast_vs_rule.png`.

## Бэктесты и калибровка по прогнозам ЦБ

    python src/backtest.py             # ex post по кварталам (использует будущие данные — верхняя граница качества)
    python src/backtest_realtime.py    # по заседаниям 2018–2026: только данные на дату + прогноз ЦБ
    python src/cbr_rule_calibration.py # шаги 1–3: правило на входах прогнозов ЦБ, надбавка ЦБ, наш прогноз

`download_data.py` скачивает PDF «Среднесрочный прогноз Банка России» (с 2019 г.) и разбирает
инфляцию (дек/дек), рост ВВП и среднюю ключевую ставку (остаток года — из сноски 1, далее по годам)
в `data/raw/cbr_inflation_forecasts.csv`.

`cbr_rule_calibration.py`: для каждого прогноза ЦБ с 2023 г. правило КПМ (месячное сглаживание 0,75^(1/3))
прогоняется на инфляции и ВВП из этого прогноза; разрыв выпуска = известный HP-разрыв + (рост − потенциальный
рост ЦБ). Расхождение с опубликованной траекторией ставки описывается затухающей надбавкой к нейтральной ставке
(общая для всех прогнозов скорость затухания, своя величина для каждого). Затем то же правило с надбавкой из
последнего прогноза ЦБ применяется к нашей инфляции и нашему ВВП.

## Вкладка «Модели ЦБ» на сайте макропрогнозов

    python src/download_data.py && python src/export_site.py

`export_site.py` пересчитывает калибровку и бэктест и пишет
`projectmacro/macro_forecast_site/data/cbr_models.json` (путь меняется переменной `CBR_SITE_JSON`).
Сайт отдаёт его через `/api/cbr_models`, страница — `/cbr-models` (шаблон `templates/cbr_models.html`).
Наш прогноз берётся из того же `macro_main_linked.xlsx`, что и на сайте, — после его обновления нужно перезапустить экспорт.
