# Вкладка «ВВП» (ветка feature/gdp)

Расчёт данных — отдельный репозиторий `~/Desktop/Совкомбанк/ВВП` (github andreynes/gdp, приватный): `run.sh`
скачивает источники (Росстат бережно — по странице раздела, файл только при смене ссылки/размера; ЦБ — мониторинг
предприятий; МЭР — «О текущей ситуации в российской экономике»), считает оценку ВВП SA (x13) и потенциал (HP),
пишет `data/gdp_activity.json`. На сайт — `./publish.sh gdp` (раздел в `data_scripts/publish.py`).
Макет — `templates/gdp.html`, маршруты `/gdp`, `/api/gdp` (за входом). Подробно — CLAUDE.md и ИНСТРУКЦИЯ.md репозитория ВВП.
